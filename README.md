# VendTON — Pitch Deck

Presentation deck for **VendTON**, a community-driven marketplace for paid APIs
on TON. Built for the BSA EPFL Hackathon 2026 (AlphaTON Capital + ENS tracks).

> APIs earn. AI pays. Wallet controls.

## About VendTON

VendTON turns the [x402](https://www.x402.org/) pay-per-request standard — on its
own just an HTTP header — into a full product: a Telegram-native marketplace
where developers publish paid APIs, AI agents and users discover and consume
them, and payments settle in USDT on TON. Identity is handled through ENS.

The deck walks through the problem (x402 has no discovery and no product), the
solution and vision, the Telegram Mini App product, how the protocol layer
works, what was built, and the market opportunity.

## The deck

A single-file [reveal.js](https://revealjs.com/) presentation (`index.html`
plus `style.css`), loading reveal.js from a CDN.

## Run it

```bash
npm run dev     # serve locally with `npx serve .`
# or
npm run open    # open index.html directly in the browser
```

Then navigate the slides with the arrow keys.
